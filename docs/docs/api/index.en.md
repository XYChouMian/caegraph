# API Reference

CAEGraph is in Phase 0 (Foundation): public classes are not implemented yet.

Once modules land, they will be documented here automatically via
[mkdocstrings](https://mkdocstrings.github.io/), e.g.:

::: caegraph
    options:
      show_source: false
      heading_level: 3

Planned top-level modules (see the architecture specification):

- `caegraph.core`
- `caegraph.data`
- `caegraph.models`
- `caegraph.physics`
- `caegraph.visualization`
- `caegraph.utils`
