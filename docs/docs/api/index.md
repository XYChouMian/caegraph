# API 参考

CAEGraph 处于 Phase 1（核心数据结构）：`BaseObject`、注册机制与共享类型正在
实现，核心公共 API 尚未发布。

模块落地后，将由此处的
[mkdocstrings](https://mkdocstrings.github.io/)
自动生成文档，例如：

::: caegraph
    options:
      show_source: false
      heading_level: 3

规划中的顶层模块（见架构规范）：

- `caegraph.core`
- `caegraph.data`
- `caegraph.models`
- `caegraph.physics`
- `caegraph.visualization`
- `caegraph.utils`
